# ADS1115 Reference Material

This directory contains the TI source material used for driver register,
timing, and electrical contract checks.

| Path | Contents |
| --- | --- |
| `ADS111x_datasheet_revE.pdf` | TI ADS111x Rev. E datasheet copy used for register, timing, and electrical contract checks. |
| `extracted-md/` | Curated datasheet-derived Markdown transcripts retained for quick human and AI-assisted review. |
| `pdf-extracted-md/ADS111x_datasheet_revE.md` | Full PDF-derived Markdown transcript retained alongside the authoritative PDF. |

The PDF is authoritative. The full and curated transcripts are navigation and
review aids; apparent extraction differences must be resolved against the PDF.

Current release documentation is in the repository root and the top-level
`docs/` files listed in `docs/README.md`.
